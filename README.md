# Perangkat Pembelajaran Bahasa Jawa

Aplikasi Flutter ini menampilkan perangkat pembelajaran untuk mata pelajaran Bahasa Jawa, yang secara khusus membahas materi cerita wayang Punakawan dan Aksara Jawa (ha na ca ra ka da ta sa wa la). Aplikasi ini menyajikan Capaian Pembelajaran (CP), Tujuan Pembelajaran (TP), dan Alur Tujuan Pembelajaran (ATP) yang disusun berdasarkan empat elemen utama: Menyimak, Membaca, Berbicara, dan Menulis.

## Fitur Utama

*   **Tampilan Terstruktur:** Menampilkan Capaian Pembelajaran, Tujuan Pembelajaran, dan Alur Tujuan Pembelajaran dalam bentuk kartu-kartu yang rapi.
*   **Empat Elemen Keterampilan Berbahasa:** Materi disusun dan dikelompokkan ke dalam empat elemen utama bahasa:
    *   **Menyimak:** Kemampuan memahami cerita dan pelafalan aksara.
    *   **Membaca:** Kemampuan membaca teks cerita wayang dan mengenali bentuk aksara Jawa.
    *   **Berbicara:** Kemampuan menceritakan kembali dan melafalkan aksara Jawa dengan benar.
    *   **Menulis:** Kemampuan menyalin dan menuliskan aksara Jawa secara tepat.
*   **Desain Responsif:** Tampilan disesuaikan untuk dapat digunakan pada berbagai ukuran layar, baik perangkat seluler, tablet, maupun desktop.

## Tumpukan Teknologi

*   **Flutter:** Framework UI untuk membuat aplikasi multi-platform dari satu basis kode.
*   **Dart:** Bahasa pemrograman yang digunakan untuk mengembangkan aplikasi Flutter.

## Cara Menjalankan

1.  Pastikan Anda telah menginstal Flutter SDK di sistem Anda.
2.  Kloning repositori ini.
3.  Jalankan perintah `flutter pub get` untuk mengunduh dependensi (jika ada).
4.  Jalankan aplikasi dengan perintah `flutter run`.
